CAW（コー）って、なに？

CAW は、会社が真ん中にいない SNS です。
X（旧Twitter）のように投稿・いいね・フォローができますが、投稿は会社のサーバーではなく、QL1 というチェーン（みんなで記録する大きなノート）に残ります。だから、運営会社の都合でアカウントが消されることがありません。

もともとは Ethereum で始まった仕組みで、これは有志が QL1 で動くようにしたコミュニティ版です（CAW公式のものではありません）。

📱 Androidアプリ（公開版 v0.4.9） 🌐 Web版を開く（iPhone・PCでもOK）

どちらも無料・オープンソースです。読むだけなら、どちらの入口も登録なしで今すぐ見られます。

ふつうのSNSと、なにが違うの？

🏢🚫

会社が真ん中にいない

投稿やフォローの記録は QL1 のチェーン上に残ります。特定の会社が「やめます」と言っても、記録そのものは残り続けます。

🏷️

「名前」がアカウント

CAW では、好きな文字列の名前を1つ取ることが、そのままアカウント作りです。名前は世界に1つだけ。取った名前は後から変えられません。

🔑

カギは自分で持つ

パスワードを会社に預ける方式ではありません。あなたの「復元フレーズ（12個の英単語）」がアカウントのカギです。無くすと誰にも直せないので、紙に書いて保管します。

できること

📰

タイムラインを読む

みんなの新しい投稿が順番に並びます。ウォレットなしでも、読むだけならすぐできます。

✏️

投稿する

名前を取れば投稿できます（1投稿は420バイトまで。日本語だとおよそ140文字ほどです）。返信や引用もできます。

❤️

いいね・Recaw

気に入った投稿に「いいね」、広めたい投稿は「Recaw」（リポストのようなもの）ができます。

👥

フォローする

気になる名前をフォローして、その人の投稿を追えます。フォロー関係もチェーンに記録されます。

⭐

超いいね（SuperLike）

アプリだけの応援機能です。1回 1,000 CAT42 のうち、500 が投稿した人へ届き、500 はバーン（消滅）します。投稿に金色の ⭐ と件数が付きます。

🪙

名前にお金を入れておく

自分の名前に qCAW を入れておくと、投稿などの料金はそこから払われます。そして、みんなが使った料金の一部がプールに集まり、入れている人全員に自動で少しずつ配られます（請求の操作は要りません）。

※ 配られる量は、その時々の利用量で変わります。今の利用量ではごくわずかです。「必ず増える」「利回り○%」といった約束はできません。

入口は2つあります

📱 Androidアプリ（おすすめ）

  • 投稿・いいね・Recaw・フォロー、全部入り
  • 名前を取る、名前への入出金もアプリの中で完結
  • アプリの中で qCAW を買う案内つきの流れ（HuntersSwap／HuntersDEX）もあります：BNB や ETH から、順番に案内通りに進むだけ
  • 超いいね（SuperLike）もアプリの機能です
ダウンロードページへ（v0.4.9）

Android 専用です。Play ストア以外からのインストールになるので、途中で確認が出たら「許可／インストール」で進んでください。

🌐 Web版（ブラウザ）

  • iPhone でも PC でも使えます。インストール不要
  • 読む・名前を取る・投稿する、がブラウザの中でできます
  • 投稿用ウォレットはページの中に作ります。カギはあなたのブラウザの中に、パスワードで暗号化されて保存され、外に送られることはありません
  • 名前を取る時だけ、手持ちのウォレットアプリを使います
Web版を開く

Web版で投稿用のウォレットを作る時も、メインのウォレットのフレーズは絶対に入れないでください。CAW専用の新しいものを作るのが安全です。

はじめ方（4ステップ）

  1. 入口を開くAndroid の方はアプリ、iPhone・PC の方は Web版を開きます。まずタイムラインを眺めて、雰囲気を見てみてください。
  2. ウォレットを作るアプリ／ページの案内で新しく作ります。出てくる12個の英単語（復元フレーズ）は、紙に書いて、誰にも見せずに保管してください。これが唯一のカギです。CAW専用に新しく作るのがおすすめです。
  3. 名前を取る使える文字は小文字の英字と数字だけです（アンダースコアや記号は使えません）。短い名前ほど高く、長い名前ほど安くなります。例（目安）：7文字で 10,000,000 qCAW、13文字で 1,000,000 qCAW。実際の価格は取る直前に画面で確認してください。名前は後から変えられません。
  4. qCAW を名前に入れて、投稿開始名前に qCAW を少し入れておけば、投稿・いいねなどの料金がそこから引かれます。手数料用の QOM が足りない時は、無料の蛇口（フォーセット）で少しもらえます。

安全のために（大事です）

🤫 復元フレーズは絶対に教えない

12個の英単語を知っている人は、あなたのアカウントとお金を全部操作できます。運営やサポートを名乗る人でも、フレーズを聞くことは絶対にありません。聞かれたら詐欺です。チャットやメールで送るのも禁止です。

🪪 CAW専用ウォレットを使おう

大きなお金を入れているメインのウォレットのフレーズは、アプリやWeb版に入れないでください。CAW用に新しく作ったウォレットで始めるのが安全です。

🧪 まだ開発中の道具です

このQL1版は有志のコミュニティが作ったもので、CAW公式のものではありません。開発途中のため、不具合が起きる可能性もあります。最初は無くなっても困らない小さな金額から始めてください。

🏷️ 名前は一生ものです

取った名前は変更できません。アイコン画像も、名前から自動で作られるカードが正本で、好きな写真に差し替える機能は今のQL1版にはありません。よく考えてから取りましょう。

よくある質問

iPhone でも使えますか？

はい。アプリは Android 専用ですが、Web版がブラウザで使えます。読む・名前を取る・投稿する、ができます。

お金はかかりますか？

読むだけなら無料です。名前を取る時に qCAW（名前の料金）と、記録の手数料として少しの QOM が必要です。投稿などの料金は、名前に qCAW を入れておいて、そこから少しずつ引かれます。

名前は後から変えられますか？

変えられません。取った瞬間に確定します。別の名前が欲しい場合は、新しくを取り直す形になります。

アカウントが消されることはありますか？

記録はチェーン上に残るので、会社都合で消える仕組みではありません。ただし、復元フレーズを無くすと、あなた自身も二度と入れなくなります。保管がいちばん大事です。

qCAW はどこで手に入りますか？

Androidアプリの中に、BNB や ETH から順番に案内してくれる買い方（HuntersSwap／HuntersDEX）が入っています。QL1 上の交換所（QomSwap）で QOM などと交換する方法もあります。

これは CAW 公式のサービスですか？

いいえ。Ethereum の CAW の仕組みを、有志が QL1 で動くようにしたコミュニティ版です。本家の考え方（マニフェスト）は caw.is にあります。
